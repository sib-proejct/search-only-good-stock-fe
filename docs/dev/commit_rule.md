# Commit

1. Check the changes.
2. Split unrelated changes into separate commits.
3. Run relevant validation when practical.
4. Propose the files and message, then get confirmation.
5. Commit only approved files.

Use this message format.

```text
type(scope): concise English summary
```

Use this body format. A Korean translation of the subject and English details.

```text
- type(scope): 간결한 영어 요약.
- English detail 1.
- English detail 2.
```
